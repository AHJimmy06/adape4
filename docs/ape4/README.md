# Entrega documental APE4 — índice para Word

Los archivos están redactados en español y pueden convertirse a Word. Mantenga la carpeta `capturas/` junto a los Markdown para resolver las imágenes relativas. No se generó un PDF institucional ni se completaron firmas/nombres de estudiantes sin datos del grupo.

## Orden recomendado de lectura/conversión

1. [GUIA_APE4.md](GUIA_APE4.md): apartados I–XI solicitados por APE4_AD.
2. [ARQUITECTURA.md](ARQUITECTURA.md): componentes, servicios, modelo y flujos; incluye PNG de arquitectura.
3. [MANUAL_USUARIO.md](MANUAL_USUARIO.md): acceso, administración, compra y cancelación.
4. [PRUEBAS_Y_EVIDENCIAS.md](PRUEBAS_Y_EVIDENCIAS.md): matriz y diferencias entre pruebas locales y remotas.
5. [ACTA_EJECUCION.md](ACTA_EJECUCION.md): resultados realmente observados, incidencias y recuperación.
6. [CAPTURAS.md](CAPTURAS.md): galería de25 capturas reales y un diagrama.
7. [REFERENCIAS.md](REFERENCIAS.md): bibliografía de la materia y documentación técnica.

Anexos técnicos: [CONTRATO_SISTEMA.md](CONTRATO_SISTEMA.md) y [NOTAS_BACKEND.md](NOTAS_BACKEND.md).

## Qué falta completar por el grupo

Nombres, identificación académica, firmas y datos de presentación institucional. Las plantillas de repetición de pruebas se mantienen expresamente como plantillas; no son resultados pendientes de la ejecución registrada.

## Límites honestos

La compra y las devoluciones se ejecutaron contra Stripe TEST y Render. La concurrencia simultánea se verificó con dos conexiones PostgreSQL locales, no como carga remota. ADMIN y globo internacional se capturaron en un entorno aislado. No se probaron dispositivos Android/iOS físicos ni tarjeta rechazada remota. El plan gratuito de Render no garantiza disponibilidad continua.
